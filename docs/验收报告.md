## 三、视觉对比结论

- 双端截图存档：`docs/screenshots/`（legacy_*.png / new_*.png，共 9 组）。
- 像素级分析：**页面背景色、主体颜色、布局结构完全一致**（如 privacy 平均色两版均 (45,76,85)）。
- 差异来源（均为非功能性）：
  1. **字体抗锯齿（AA）**：Chrome 渲染与旧版 CDN AfterBody.js 注入字体不同导致边缘像素差；
  2. **随机内容**：首页随机推荐顺序每次不同；
  3. header 顶部渐变有 ±4 色值微差（legacy theme-color meta 与新版 head 配置差异）。

## 四、技术验收

- Go 后端：`go build ./...` 通过；`go vet` 无错误；API 全端点 curl 冒烟通过。
- Next.js：`tsc --noEmit` 通过；全部页面 200 渲染。
- 数据库：20 张表（含 sessions 与 7 张会馆系列表，旧 `world` 已移除）通过 golang-migrate 创建；seed 数据可用。
- 性能：Go 进程内 LRU 缓存（posts 30s/detail 60s/guilds 30s/search 120s）。

## 五、已知差异与后续建议

1. **Live2D**：原版 canvas 引擎复杂，ov2 用本地 GIF 轮播（展示效果一致，交互简化）。
2. **SW 缓存策略**：ov2 sw.js 仅缓存静态资源，页面网络优先（防旧壳）。
3. **legacy 归档**：旧代码已移出本仓库——完整版归档为工作区根 `forum-legacy/`（克隆自上游 [crazying-dev/forum](https://github.com/crazying-dev/forum)，独立仓库、不维护）；原 `legacy/` 子集已删除（2026-10-04）。
4. **SMTP**：`server/.env` 的 `SMTP_PASSWORD` 需用户填入真实凭据后验证码邮件才可发送（开发已确认走真实 SMTP）。
5. **生产上线**：按 `deploy/README.md` 步骤（Go systemd + Next standalone + Nginx + 外部 PGSQL）。
